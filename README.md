**CaveViewer3** — высокопроизводительное мобильное Android-приложение для просмотра, калибровки, точных измерений и векторного аннотирования спелеологических топосъемок, планов пещер и крупномасштабных растровых карт.
---
## 🌟 Основные возможности
### 🗺 1. Высокопроизводительный растровый движок
- **Pyramidal Tile Cutter**: локальная нарезка сверхвысокодетальных сканов топосъемок на тайловые пирамиды без потери детализации.
- **MapLibre GL Native**: плавный 60 FPS рендеринг с аппаратным ускорением.
- **Фильтры карты**: инверсия цветов (для сканов тушью/чертежей), тонкая настройка контрастности и насыщенности.
### 📐 2. Геологический и спелеологический измерительный комплекс
| Инструмент | Назначение |
| :--- | :--- |
| **📏 Линейка** | Многосегментные полилинии, замер расстояний (в метрах или пикселях). |
| **📐 Площадь** | Расчет площади многоугольников и залов ($м^2$, $px^2$). |
| **📐 Угол** | Определение углов по 3 вершинам (ход, ветвление). |
| **🧭 Азимут** | Замер азимутов с автоматической компенсацией угла истинного севера (`angleNorth`). |
| **⚡ Ось разломов** | Анализ тектонических направлений и трещиноватости. |
| **📍 Смещение (ΔX, ΔY)** | Расчет горизонтального и вертикального смещения между пикетами. |
| **⭕ Радиус** | Буферные зоны и радиусы обзора. |
### 🧲 3. Векторные слои и CAD Snapping
- Полнофункциональные **точечные** и **линейные** слои с пользовательскими атрибутами и цветовыми палитрами.
- **SnappingEngine**: магнитное прилипание курсора к вершинам (`Vertex`), граням (`Edge`), пересечениям (`Intersection`) и точкам (`Point`).
- Оптимизированный рендеринг: **Bounding Box Viewport Culling** и предкэширование гео-координат.
### 📍 4. Геопривязка и кадастровые метаданные
- Привязка входов пещер к географическим координатам (WGS-84) с поддержкой **OSM Geocoding**.
- Калибровка масштаба ($px/m$) и направления севера.
- Встроенный редактор кадастровой карточки (глубина, амплитуда, категория, регион).
- Импорт и экспорт проектов с шифрованием архивов.
---
## 🏗 Архитектура и технологии
Приложение построено по принципам **Clean Architecture** и **MVI (Model-View-Intent)**:
- **Язык**: Kotlin 2.x (Coroutines, StateFlow).
- **UI**: Jetpack Compose + Material 3.
- **DI**: Koin.
- **Картография**: MapLibre GL Native SDK.
- **Хранилище**: DataStore Preferences, локальный JSON/SQLite storage, Zip4j.

## 🚀 Сборка и запуск
1. Клонируйте репозиторий:
```bash
git clone https://github.com/vktrsansara/CaveViewer3.git
```
2. Откройте проект в Android Studio
3. Дождитесь синхронизации Gradle и соберите проект
```bash
./gradlew assembleDebug
```
